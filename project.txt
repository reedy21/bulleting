# Разработка веб-приложения онлайн-доски объявлений на основе Python и Django

## Общая информация
**Название проекта:** Разработка веб-приложения онлайн-доски объявлений с аукционом на основе Python и Django  
**Тип:** Курсовая работа по направлению «Программная инженерия»  
**Цель:** Создать рабочую платформу для размещения, поиска и взаимодействия с объявлениями (аналог упрощённого Avito), а также создания аукционов.

## Технологический стек (упрощённый)
- **Backend:** Python + Django (последняя версия)
- **Frontend:** HTML + CSS + Bootstrap 5 + JavaScript (vanilla, без React)
- **База данных:** PostgreSQL
- **Аутентификация:** Django встроенная + простые формы
- **Хранение фото:** Django + Media-файлы (локально)
- **Реал-тайм чат:** Django Channels + WebSocket
- **Дополнительно:** Django Admin

## Роли пользователей
1. **Гость** — может только просматривать объявления
2. **Зарегистрированный пользователь** — публикует объявления, пишет другим пользователям с объявлениями, добавляет в избранное, смотрит историю просмотров и участвует в аукционах
3. **Администратор** — модерирует объявления и управляет категориями

## Основной функционал
- Регистрация и вход
- Публикация объявлений (до 10 фотографий, категории, цена, регион, тип: продажа/услуга/обмен)
- Поиск и фильтры объявлений и аукционов
- Просмотр карточек и детальной страницы объявления
- Участие в аукционах
- Личный кабинет (мои объявления, избранное, уведомления, история просмотров, аукционы)
- Реал-тайм чат между пользователем и автором
- Простая админ-панель для модерации

## Разбивка проекта на 7 спринтов (21 задача)

**Спринт 1: Настройка проекта и база данных** (3 задачи)  
1. Создать Django-проект, подключить PostgreSQL, настроить настройки  
2. Создать приложения (accounts, ads, core) и первые модели User и Category  
3. Настроить Django Admin и добавить тестовые данные  

**Спринт 2: Авторизация и базовые страницы** (3 задачи)  
4. Реализовать регистрацию, вход и выход  
5. Создать главную страницу и базовый шаблон с Bootstrap  
6. Сделать навигацию  

**Спринт 3: Создание и просмотр объявлений** (4 задачи)  
7. Модель объявления + загрузка нескольких фотографий  
8. Форма создания/редактирования объявления  
9. Страница списка всех объявлений (карточки)  
10. Детальная страница одного объявления + просмотры и избранные

**Спринт 4: Поиск, фильтры и личный кабинет** (3 задачи)  
11. Поиск по названию и описание + фильтры (цена, категория, регион)  
12. Личный кабинет пользователя (мои объявления)  
13. Добавление в избранное и страница избранного  

**Спринт 5: Взаимодействие пользователей** (3 задачи)  
14. Чаты пользователей 
15. Сохранение в БД
16. История просмотров 

**Спринт 6: Реал-тайм чат и улучшения** (3 задачи)  
17. Подключение Django Channels и WebSocket  
18. Возможность удалять/редактировать сообщения в чате
19. Редактирование дизайна
20. Добавление аукциона 

**Спринт 7: Админ-панель, тестирование и финализация** (2 задачи)  
21. Модерация  
22. Тестирование всего проекта, исправление ошибок, подготовка отчёта и презентации

Всего: 22 задача.
